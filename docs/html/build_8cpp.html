Builds a structured and filtered transaction dataset from parsed input.

Transforms a parsed_file into a built_file by filtering low-utility items, remapping item IDs, and computing statistics like TWU and max transaction size.

Parameters
pfThe parsed file input.
threadsNumber of threads to use (OpenMP enabled).
timerA Timer object for benchmarking.
min_utilityThe minimum utility threshold to keep an item.
Returns
A built_file structure containing the processed transaction data.
