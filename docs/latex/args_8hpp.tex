\doxysubsection{Detailed Description}
Lightweight C++ command-\/line argument parser. 

This file declares the \doxylink{classArgParser}{Arg\+Parser} class, which supports defining and parsing flags, required arguments, and optional arguments with default values. It also provides type-\/safe getters, validation, and an auto-\/generated help message.

The file also includes a helper function, get\+Separator, to convert string representations of separators (e.\+g., "{}\textbackslash{}\textbackslash{}s"{}, "{}\textbackslash{}\textbackslash{}t"{}) into their corresponding character values.

\begin{DoxyNote}{Note}
The parser exits with an error if arguments are invalid or required ones are missing. 
\end{DoxyNote}
