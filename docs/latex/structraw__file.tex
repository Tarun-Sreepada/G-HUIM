\doxysubsection{Detailed Description}
Holds raw file data and associated metadata. 

Represents a raw file loaded into memory.

This structure contains\+:
\begin{DoxyItemize}
\item The file\textquotesingle{}s data in memory.
\item Metadata about the file, including size, submitted, retrieved, and processed bytes.
\item A vector of retrieved indices for tracking processed data.
\item The file descriptor for the opened file.
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The {\ttfamily close} method should be called to free allocated memory. 
\end{DoxyNote}
